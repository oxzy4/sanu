PANDA BIRTHDAY WEBSITE — WITH YOUR PHOTOS

This folder contains the updated website and the three supplied photos.

LOCAL PREVIEW
1. Open this folder in VS Code.
2. Open index.html with Live Server, or double-click index.html.
3. Enter the passcode you configured in CONFIG.

PUBLISH THE PHOTO UPDATE
1. Open https://github.com/oxzy4/panda-birthday
2. Upload the updated index.html.
3. Upload the entire assets folder containing:
   - panda-memory-1.jpg
   - panda-memory-2.jpg
   - panda-memory-3.jpg
4. Keep the assets folder beside index.html in the repository root.
5. Commit changes and wait for GitHub Pages to redeploy.
6. Refresh https://oxzy4.github.io/panda-birthday/

IMPORTANT
- Keep the filenames exactly as shown; the HTML uses those paths.
- The photos are included in the website and will be visible to anyone who can access the public site.
- Only publish photos that the people shown are comfortable sharing.
- Before sharing the QR code, test the live site on a phone.
- The passcode is already set to "2066". The birthday countdown still needs the complete birthday in YYYY-MM-DD format. Replace "YYYY-MM-DD" in CONFIG once you know the day.
